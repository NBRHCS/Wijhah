# وجهة (Wijhah)

[English documentation](README.en.md)

«وجهة» منصة عربية أولًا، ثنائية اللغة، تساعد الطلاب والخريجين ومن يبحث عن اتجاه جديد على استكشاف المسارات التعليمية والمهنية بصورة منظمة. تجمع المنصة بين تقييم تكيفي للميول، واستكشاف واسع للمجالات، ومقارنات مباشرة، وخرائط طريق قابلة للحفظ والمتابعة.

يغطي الإصدار الحالي 21 مجالًا مهنيًا و103 مسارات، ويعرضها بالعربية والإنجليزية دون إعطاء أفضلية تلقائية للمجالات التقنية أو الأعلى دخلًا.

**حالة المشروع:** إصدار مفتوح المصدر أولي قابل للتشغيل والمساهمة، مع استمرار تطوير المحتوى وتجربة الاستخدام.

> النتائج إرشادية للاستكشاف واتخاذ خطوة تالية أوضح، وليست تشخيصًا لقدرات المستخدم أو ضمانًا للتأهيل أو التوظيف. يجب التحقق محليًا من متطلبات المهن المنظمة وبيانات سوق العمل.

## المميزات

- واجهة عربية RTL كاملة مع نسخة إنجليزية LTR.
- تقييم تكيفي يبدأ باستكشاف واسع ثم ينتقل إلى أسئلة أعمق في المجالات المختارة.
- نتائج مرتبة مع توضيح حالات التعادل وعدم اكتمال الإجابات.
- استكشاف وتصفية لمسارات من عائلات مهنية متنوعة.
- خريطة تربط الاهتمامات والمجالات بمسارات قابلة للاستكشاف.
- مقارنة حتى ثلاثة مسارات في جدول واحد.
- خرائط تعلم عملية ومتابعة الإنجاز لكل مسار.
- حفظ محلي للمسودة، مع دعم حفظ التقدم للمستخدم المسجل عند توفر بيئة الاستضافة.
- مظهران كاملان، فاتح وداكن، مع حفظ اختيار المستخدم.
- تجربة متجاوبة ودعم للتنقل بلوحة المفاتيح والحركة المخففة.

## لقطات الشاشة

لقطات الشاشة ستُضاف في إصدار لاحق. اللقطات المقترحة:

- الصفحة الرئيسية بالمظهر Theme 2.
- رحلة التقييم.
- صفحة النتائج.
- خريطة المسارات.
- خريطة طريق مهنية بالمظهر Theme 6.

## التقنيات المستخدمة

- React 19 وTypeScript.
- واجهات Next.js App Router تعمل عبر Vinext وVite.
- Tailwind CSS 4 ومكونات shadcn/Radix وأيقونات Lucide.
- Cloudflare Workers وD1 للتشغيل والحفظ الاختياري.
- Drizzle ORM لإدارة مخطط قاعدة البيانات.
- ESLint واختبارات Node لنظام التقييم.

## بدء التشغيل محليًا

### المتطلبات

- Node.js 22.13 أو أحدث.
- npm المرفق مع Node.js.

### التثبيت

```bash
git clone https://github.com/NBRHCS/Wijhah
cd Wijhah
npm ci
```

لا توجد متغيرات بيئة مطلوبة حاليًا. يمكنك إنشاء ملف محلي من القالب للحفاظ على مسار إعداد ثابت:

```bash
# macOS / Linux
cp .env.example .env.local

# Windows PowerShell
Copy-Item .env.example .env.local
```

ابدأ خادم التطوير:

```bash
npm run dev
```

افتح العنوان الذي يطبعه Vite في الطرفية. تستخدم بيئة التطوير قاعدة D1 محلية وهوية تسجيل دخول وهمية لطلبات loopback فقط؛ لا تعمل هذه الهوية في بناء الإنتاج.

## أوامر المشروع

| الأمر | الغرض |
| --- | --- |
| `npm run dev` | تشغيل بيئة التطوير المحلية. |
| `npm run build` | إنشاء بناء الإنتاج. |
| `npm run start` | تشغيل بناء الإنتاج محليًا عبر Wrangler بعد البناء. |
| `npm run lint` | فحص TypeScript وReact وNext.js باستخدام ESLint. |
| `npm run typecheck` | فحص الأنواع دون إنشاء ملفات. |
| `npm run test:assessment` | تشغيل اختبارات صحة وتوازن نظام التقييم. |
| `npm run db:generate` | إنشاء migration من مخطط Drizzle. |

## هيكل المشروع

```text
app/                  الصفحات، رحلة المستخدم، منطق التقييم، وواجهات API
  api/saved/          حفظ واسترجاع تقدم المستخدم
  themes/             مزود المظهر ومبدّل المظاهر
build/                تكامل Vinext المحلي مع بيئة الاستضافة
components/ui/        مكونات الواجهة القابلة لإعادة الاستخدام
db/                   مخطط Drizzle والوصول إلى D1
drizzle/              migrations قاعدة البيانات
public/               الأصول العامة
scripts/              أدوات التشغيل والبناء وCI
tests/                اختبارات نظام التقييم
vendor/               ملفات طرف ثالث مضمنة مع تراخيصها
.github/               CI وقوالب المساهمات وDependabot
docs/                  توثيق إعداد المستودع
```

## المظاهر

يدعم «وجهة» مظهرين من مبدّل المظهر في الترويسة:

- **Theme 2:** مظهر فاتح ودافئ، وهو الافتراضي.
- **Theme 6:** مظهر داكن وعصري.

يُحفظ الاختيار في المتصفح، ويُطبق قبل ظهور الواجهة لتجنب وميض المظهر الافتراضي.
